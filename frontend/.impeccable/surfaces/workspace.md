Mode: Operate. Scope: all existing frontend routes and states. Code-led implementation.

## Direction contract

THESIS: A composed project steward keeps commitments visible. A usable working app, with a character that provides occasional direction rather than decorating every object.

OWN-WORLD: Pale mineral canvas, white working surfaces, pine actions, slate text, muted ochre attention and clay errors. Public Sans, precise 8px spacing, compact outlined icons, 12px panel corners. One charcoal rook in a green chore jacket holding a clipboard.

STORY: Find the current project and identity, understand the next checkpoint, act or ask for help, then inspect evidence privately. Preserve all existing workflows and truthful statuses.

FIRST VIEWPORT: Desktop left navigation rail; project and identity in a top utility bar. Dashboard heading followed by a low, wide Enforcer briefing. Tasks lead the main column; overall progress, history and team status form a supporting column. On phones navigation becomes a compact disclosure, followed by the same content in reading order.

FORM: Direct brief-led replacement under the launcher's unavailable fallback. The seed roll was skipped: the first attempt refused missing PRODUCT.md, then the project launcher disappeared when the work was isolated on main. This is not a validated unavailable-seed reference. Product truth and the explicit user brief govern the implementation; user delegates character design. Signature interaction: responding to a reminder returns a clear confirmation; primary buttons give quiet press feedback; reduced motion removes motion.
